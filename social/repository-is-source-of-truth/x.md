# X投稿案

## 案1: 実体験から入る

AIに「次何作ろう？」と聞いたら、候補に出てきた機能がもう自分のRepositoryにありました。

しかも、思っていたよりちゃんと作り込んでいた。

それからAI開発エージェントには「Repository is the Source of Truth」をかなり強く入れています。

会話やIssueではなく、毎回Repositoryから現在地点を取り直すようにしたら、個人開発の進め方がかなり変わった話を書いています。

## 案2: プロンプトの鮮度から入る

AI向けの引き継ぎプロンプトを長く書けば書くほど、数日後にはそこに書いた「現在の状態」が古くなる。

最近は現在地点を細かく書くより、Repository / PR / Issue / Docs / CIを見て毎回再構築させるようにしています。

「Repository is the Source of Truth」にして何が変わったか、個人開発の実例ベースでまとめる予定です。
